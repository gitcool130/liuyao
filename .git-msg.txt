feat(同步): 个人卦例库支持 OneDrive / WebDAV 多机同步

王哥要「把个人卦例同步到 OneDrive 或 WebDAV」，参照 LightRead 的做法。
需求背后最要紧的一点：**同步不能覆盖，要合并**——两边各自存过卦例，
整库覆盖一定丢数据。

## 两个关键事实（决定了实现方式）
1. **OneDrive 没有公开的 WebDAV 端点了**（早年 SkyDrive 有，2016 年前后关闭），
   所以 OneDrive 走「直接写你本机的 OneDrive 文件夹」，由官方客户端上传。
   好处：不需要登录、不要令牌、不碰任何凭据。
2. **WebDAV 必须由外壳代发请求**：浏览器里 PROPFIND 的跨域预检必然失败，
   Basic 认证头也会被拦。所以 .NET 侧用 HttpWebRequest 发 LIST/READ/WRITE。

## 合并策略（照 LightRead 的「状态型同步」）
- 每台设备只写**自己**的文件（devices 里 `<deviceId>.json`），绝不写别人的
  → WebDAV 没有可靠锁，只写自己的就不会互相踩
- 合并 = 按记录 id 取并集，同 id 取 updated_at 更新的那份（LWW）
- **删除留墓碑**：只记 id + 删除时间。没有墓碑的话，别的机器一同步就把删掉的
  卦例「复活」——多机同步最经典的坑，端到端专门验了这一条
- 墓碑比记录新才算删除；记录比墓碑新（删后悔了又改过）则记录胜出、墓碑作废
- 合并满足交换律/结合律/幂等：同步多少次、什么顺序，结果都一样（有单测）

## 数据层
- 本地层加 `POST /api/records?replace=1` 整库落地通道。**不能逐条 POST**：
  每次写都会把 updated_at 刷成「现在」，合并依据就被自己改写掉了
- 删除卦例时记墓碑（delCast 里）
- 设备号与墓碑存 `同步状态.json`（桌面壳里落文件，清浏览器缓存也不丢）

## 界面
- 卦例库按钮行加「同步」；点开面板选 OneDrive / WebDAV
- OneDrive 区直接显示找到的同步目录；WebDAV 区填地址/账号/密码
- 「立即同步」完成后报「从别的设备取来 N 条、移除 N 条、几台设备参与合并」
- 「打开程序时自动同步」可选，延迟 4 秒跑，不抢首屏
- 没找到 OneDrive 时明确说怎么办，不静默失败

## 测试
- test-sync.js 30 项：后写胜、墓碑传播、删除不复活、交换律/结合律/幂等、
  脏数据（别的 JSON、非法 id、超大记录）不污染
- test-ui-sync.js 18 项：真实浏览器里跑两台「设备」共享一个假 OneDrive 目录，
  验首次同步不丢本地、B 新增 A 能看到、A 删除 B 也删、反复同步结果不变
- 顺手修了个真 bug：isRecord 只查 id 长度不查字符集，`bad id!!` 这种能混进
  合并结果，落地时被本地层白名单整条丢掉——「同步说成功但这条不见了」
